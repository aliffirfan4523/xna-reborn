# Product: XNA Reborn

XNA Reborn is a desktop migration and compatibility studio that brings old Microsoft XNA game projects back to life on modern Windows, using MonoGame as the foundation.

- Hackathon category: Resurrection (Kiroween).
- We do NOT recreate XNA. We analyze, convert, and run existing projects on MonoGame.
- Demo flow: open old project, analyze, migrate, build and run, show score improvement.
- Primary users: developers and hobbyists with stranded XNA projects.
- Success means a real old project goes from failing to running with minimal manual work.
