# Safety rules

1. Never modify the user's original project. All changes go to a migrated copy in a new folder.
2. The analyzer opens files read-only and must have a test proving file hashes are unchanged.
3. Never overwrite an existing output folder without explicit confirmation.
4. Never upload user source code or assets anywhere without explicit, per-project opt-in. AI repair is off by default.
5. Only include sample projects whose licenses allow redistribution, with attribution.
6. Do not bundle or redistribute commercial games.
